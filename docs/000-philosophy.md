# 000 · Philosophy

## 它解决什么问题

写过长文档——毕业论文、合同、标书、技术手册——大概经历过这些：

| 折磨 | 引擎怎么做 |
|------|---------------|
| 封面莫名其妙出现页眉，删不掉 | 前置页（封面/声明）自动清空页眉页码 |
| 正文各章页眉全是「参考文献」 | 每节创建独立页眉，各章自动显示对应标题 |
| 目录页码对不上实际内容 | 页码分节编号：前置罗马数字、正文阿拉伯数字 |
| 每章开头歪在偶数页上 | 奇偶页强制：空白页插入 + 奇数页起始 |
| 中英文混排字体乱套 | 中文宋体/标题黑体，英文 Times New Roman，Ascii/EastAsian 分离设置不打架 |
| 改完一版学校规范又变了，重调一遍 | 规范模板驱动：换一份规范 docx，重跑一条命令 |

## 设计前提

- **模板是规范权威，源文档不是**：源文档只提供排什么（内容结构），不定义怎么排（格式取值）。字号线距页边距必须从模板的 OOXML 里读出来，不用常量、不猜。
- **只修格式，不动内容**：排版修正工具，不是文档生成器。
- **OOXML ZIP 层直改**：所有操作直接读写 docx 包内 XML，排版链路不依赖 Word/LibreOffice 运行时（`enforce` 的奇偶页强制例外，需 LibreOffice）。
- **诊断闭环**：排版后自动跑 Fixer 诊断，残留为 0 才算完成——不静默失败。

## 能力清单

| 能力 | 说明 |
|------|------|
| 页眉 | 全文各节独立页眉（封面/声明自动清空） |
| 页码 | 前置罗马数字 / 正文阿拉伯数字 / 封面前置无页码 |
| 奇偶页 | 每章奇数页起始 / 扉页空白页插入 |
| 字体 | 中文宋体+标题黑体 / 英文 Times New Roman（Ascii/EastAsian 分离） |
| 边距 | 严格对齐规范模板（分节几何按角色配对模板真值） |
| 分节符 | 拆分合并节 / 补断链引用 |
| 目录 | 源文档有目录才迁移（域链继承），没有就不动 |
| 诊断 | 排版后自动 Fixer 诊断，0 残留才通过 |

## 命令

| 命令 | 作用 |
|------|------|
| `earlyz format <文档> --spec <规范>` | 按规范模板排版 |
| `earlyz analyze <规范>` | 提取格式规则 → YAML |
| `earlyz enforce <文档>` | 奇偶页强制（需 LibreOffice） |
